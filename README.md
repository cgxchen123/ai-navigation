# AI 工具导航站

一个免费的 AI 工具导航网站，类似于 zhouz.online

## 功能

- 🔍 搜索 AI 工具
- 📁 分类筛选（聊天、图像、编程、办公等）
- ❤️ 收藏常用工具
- 🌙/☀️ 深色/浅色主题切换
- ✨ 粒子动画背景
- 📱 响应式设计

## 工具列表

- ChatGPT、Claude、Gemini、DeepSeek
- Midjourney、DALL-E、Stable Diffusion
- Cursor、GitHub Copilot
- Perplexity、秘塔搜索
- Suno、ElevenLabs
- DeepL 翻译
- 等 40+ 工具

## 免费部署

### GitHub Pages（推荐）
1. 创建 GitHub 仓库
2. 上传 index.html
3. Settings → Pages → 选择 main 分支
4. 获得免费网址

### Netlify
1. 打开 https://app.netlify.com/drop
2. 拖拽文件夹上传
3. 获得免费网址

### Vercel
1. 连接 GitHub 仓库
2. 自动部署
3. 获得免费网址

## 自定义

编辑 index.html 中的 `tools` 数组即可修改工具列表。
